# LibreLoop

A small, self-contained Linux DAW written in C with raylib and miniaudio. Work in progress.

![LibreLoop](docs/images/libreloop.png)

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/libreloop
```
