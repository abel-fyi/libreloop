# Compact gray chrome and dotted editing surfaces

The user explicitly superseded the large blue reference captions with smaller gray title bars, thinner borders, and more dotted editing surfaces. Studio titles are 24 logical units (previously 32), with 16-unit rendered type and 18×18 close faces inside a 24-unit title hit region. Carried content translates by 6 units instead of 14. Browser, floating editors, main pages and titled dialogs use the same gray material. Outer window borders are one logical pixel. The legacy layout is unchanged.

Arrangement, piano note rows and velocity backgrounds reuse the existing 4-unit cyan dot tile. Notes, waveforms, automation, velocity stems and selection draw above it. Timeline grid formulas, snapping, note hit tests, velocity mapping, zoom sensitivity and audio processing remain unchanged. The caption/close geometry fixtures were updated to the requested smaller dimensions, including a check that y=24 is outside the title. Font bounds are checked at five densities. No behavioral assertions or frozen original fixtures were weakened.

All 137 tests passed; after adding explicit compact-caption bounds, the workspace/font/theme subset passed again. Software captures were inspected under `../../baseline-artifacts/90s-gray/`. A font bounds check caught padding extending beyond a 24-unit title at 18-unit type; rendered title type was reduced to 16 to fit.

Before that final font reduction, isolated sequential software-renderer profiles at 1448×1086 measured 500 active pan/zoom/playback frames after 40 warmup frames: styled p50 17.749 ms, p99 18.619 ms, max 20.973 ms, rendering CPU 9.078224 seconds; flat comparison p50 10.233 ms, p99 10.872 ms, max 12.830 ms, rendering CPU 5.238983 seconds. Both reported an audio device started. These measure the complete scene and the broad decorative-face toggle, not isolated dots, physical GPU performance or audio latency. Dots are present in both variants. No CPU saving is claimed. The earlier dialog profile ran concurrently with tests and is not used for comparison. Native GPU/HiDPI, trackpad feel and battery cost remain unverified.

The executable measured 3,744,320 bytes before final caption-font fitting. Dots reuse the 32 KiB generated texture and add no asset/dependency or idle animation. The SDL blocking wait remains unchanged; production enables it after 150 ms inactivity when playback, meters, spectra, drags, loading and count-in have settled. Smoke/profiling deliberately bypass idle waiting, so their timings do not measure idle CPU.
