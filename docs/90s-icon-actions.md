# Icon actions and filled Mixer width

The user requested icons throughout action controls, including File/Edit/View/Help. The shared button renderer now maps explicit action captions to original colored pixel sprites, retaining those captions for hover descriptions and keyboard menu navigation. Names, numeric values, device/preset choices and parameter labels remain text. The original reference atlas count and packing are unchanged; the studio atlas adds 20 original GPL sprites, not Microsoft artwork. It contains 40 icons, rasterized once per DPI change. Main File/Edit/View/Help popup action strips are compact icon columns; legacy menu dimensions are unchanged. Pattern/Song playback mode and Arrange/Pattern page buttons also use icons. Mute and solo use speaker/headphone pictograms.

Mixer strips share a width derived from available space and visible insert count, filling the area before the effects panel. Drawing, routing sockets, cable paths and scrolling all use that width. A small gutter remains between strips and the panel. Engine routing and insert count are unchanged. Geometry tests update only studio route coordinates from the former 112-unit stride to the new 121-unit stride at the 1200-unit test viewport; original reference fixtures remain unchanged. Coverage tests check widths 652–1800 and all supported insert counts.

The full suite passed 136/137 on the initial update, with the remaining routing test detecting the intentionally changed target coordinates. All six affected icon, route, slot and original menu/piano replay checks passed after that geometry update. Final integration reruns are recorded in the subsequent shadow/track-header checkpoint. Software captures were inspected at 1448×1086 and 900×562. The release executable measured 3,760,864 bytes (+16,544 from the gray-caption checkpoint). At 1x the generated studio icon atlas is 40×28×64×4 = 286,720 raw bytes, replacing the previous 143,360-byte atlas. No new dependency or bitmap file is loaded; native GPU/HiDPI and physical-input checks remain unverified.
