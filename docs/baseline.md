## Deterministic original-rendered fixtures

Temporary source harnesses in `../baseline-artifacts/harness/`; compile/link directly against unmodified `baseline-build/core/libengine.a`. PCM paths call original render_mixer_io/render_audio, the shared DSP/mixer path invoked by real-time callback. This establishes engine render references, **not full audio.c callback envelopes/mailbox/miniaudio outputs**; that missing coverage is an explicit pre-port gate.

`audio/manifest.json`:17 original benchmark fixtures at64 and512 frames, each1s requested (rounded up to whole block),128 warmup blocks. Names: idle_no_rack, idle_rack, idle_monitor, demo_song, sampler_32/128, song_100, sampler_32_stretch/chorus/eq, fm_8/32/128, fm_legacy_32, fm_32_motion, fm_analog_8/32. Source benchmark scenario setup unchanged; external copy only writes raw PCM. Captured timing values include that fwrite and are **not performance results**. Compare fixture SHA256 and exact FNV bytes only. Every fixture rerun in a fresh process matched exactly (max error0, sample/timing output deterministic). Demo starts after warmup, not from song frame0.

`audio/features/manifest.json`:8 feature modes at64/512,3s=144000 frames, no warmup, sequence+live render path. Each directory preserves original-written input.llp, source-0/1.f32, expected.f32, expected-state.txt (frame/last_step/clock_BPM per block), and expected-export.wav. Sources generated by integer remainder arithmetic, independent of random/libm generation. Project references remain @empty; harness explicitly supplies archived PCM to the channel array, rather than loading sources through paths. Port regression runner must preserve this setup.

| Mode | Coverage |
| --- | --- |

All modes change BPM123.5->80 and master pitch->2 before block at16384; modes2/3 change clip offset at32768 and set resync. Those boundaries exist in both64/512 streams. Export is captured before these edits, whole initial Song through original export_wav (48k PCM16), proving file boundary behavior independently of three-second float fixtures. Live source begins at frame0 with remaining2400/gain.1. Exact source harness records every setting/expression; retained harness SHA256 is part of artifact manifest. Repeated exports, PCM, input projects, source files and timing text match byte for byte.64/512 fixtures are independent expected references, not an assumption of universal block-size invariance.

Total50 engine PCM fixture files plus16 exported WAV files. Both SHA256 and repeat verification are retained.
