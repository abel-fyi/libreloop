LibreLoop's bundled Kick, Snare, Hat and Tone are synthesized demo one-shots,
generated by LibreLoop rather than taken from sample packs. Each WAV is mono
PCM16, 48 kHz, and half a second long. They are free to use in your music.

To regenerate them from LibreLoop's synthesis code:

```sh
cmake --build build --target make_samples
mkdir -p samples/drums samples/melodic
./build/make_samples samples
```
